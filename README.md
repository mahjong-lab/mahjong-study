# 麻雀学習アプリシリーズ 🧩🀄

ゼロから麻雀ルールを触って覚える超入門パズルと、役・鳴き判定・頻出点数を直感パターンで身につける実戦トレーニングボードの2段階Webアプリです。

## 🌐 公開ページ
1. **超入門編：[麻雀ファーストステップ 🧩 ゼロからパズル入門](https://mahjong-lab.github.io/mahjong-study/beginner.html)**
   - 14枚の手牌を見る前に、「絵柄の見分け → 3枚ブロック穴埋め → 8枚ミニ麻雀 → 13枚の待ちあて（補助輪ON/OFF対応） → 3大武器＆ドラ表示・フリテン → ポン・チー・カン合体入門」の全6ステージ（全114パターン収録・未出題優先ランダム出題）で自然に基礎と麻雀用語が身につきます。
2. **基礎・実戦編：[麻雀トレーニングボード 🀄](https://mahjong-lab.github.io/mahjong-study/)**
   - 符計算の足し算は一切なし。常設カンペを見ながら2〜3択で「役の判定・鳴いていい手か・頻出点数」をパターンで習得できます。

## ✨ 特徴
- **段階的スキャフォールディング設計**: 2〜3枚のパズルから8枚、13枚（ワンタップでブロック区切り補助輪ON/OFF）、14枚の実戦形へと無理なくステップアップ。
- **1問ごとの麻雀用語ポップアップ**: 問題を解くたびに関連する麻雀用語カードが表示され、遊びながら用語が自然に定着。
- **リアルな日本式SVG麻雀牌**: 1索（鳥）や真っ白な白（ハク）、赤ドラなど視認性の高いSVG牌グラフィック。
- **本格発声＆打牌サウンド**: 「ポン！・チー！・カン！・ツモ！・ロン！」の日本語発声と打牌物理サウンドを搭載。
- **常設カンニングペーパー＆基礎メモ**: 暗記不要でいつでも確認可能。
