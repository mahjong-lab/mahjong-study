# マシコさん専用 麻雀学習ボード 🀄

約10年のブランクがあり、役や点数計算の定着に強い苦手意識を持つユーザー「マシコさん」が、挫折せずに麻雀の基礎（役の識別・頻出点数申告）を体感的に身につけられる学習Webアプリです。

## ✨ 特徴
- **「計算」させるな、「パターン」で叩き込め**: 符計算の足し算は一切なし。画像認識のように直感で覚える。
- **スモールステップ（1問1概念）**: 1セッション最大3〜5問、選択肢は2〜3択（迷わない）。
- **リアルな牌姿グラフィック**: 文字列ではなく、本物の麻雀牌のような厚みと立体感を持つSVG牌。
- **常設カンニングペーパー（チートシート）**: 画面右上に常備。見ながら解いて自然に覚える。
- **挫折ゼロの温かいフィードバック**: 正解時は明るいチャイムと紙吹雪。不正解時もペナルティ感なく1行で優しくフォロー。

## 🀄 カリキュラム
1. **牌を見て役を当てる（基本役の復習）**: タンヤオ、平和、役牌、一盃口、七対子、トイトイなど
2. **Phase 1: 鳴いていい手？ ダメな手？（○×判定）**: 役なしチョンボを絶対に防ぐ特訓
3. **Phase 2: この手、何飜？ カウント**: 役とドラを指折り数える感覚を掴む
4. **Phase 3: 子の超頻出4大点数マッチング**: 鳴き手（1000→2000→3900）、門前ロン（1300→2600→5200）
5. **Phase 4: 親の点数 & ツモ申告**: 親ロン（1500→2900→5800）、ツモコール（〇〇オール / 親が多く払う）
6. **今日の3問 サクッと特訓**: 毎日1分で気軽に継続！
